# 人类训练体系：动作库

动作库中的每个动作独立保存为一个 Markdown 文件。动作不是孤立的“动作名称”，而是训练任务的载体；同一个动作在不同负荷、速度、幅度、支撑、感觉、认知和疲劳条件下，可能产生不同的主要适应。

## 3. 目录组织与标签

动作可以按主要用途建立分类目录，同时在文件头使用多个标签表达跨模块关系。目录是主要检索路径，标签用于多角度筛选；一个动作只放在一个主分类中，避免复制多个版本。

建议分类：

```text
动作库/
├── 力线恢复/
│   ├── 下肢承重链/
│   ├── 上肢肩带传力链/
│   └── 脊柱胸廓骨盆/
├── 基础动作/
├── 负荷与力量/
├── 体能与移动/
├── 速度爆发与弹性/
├── 敏捷变向与反应/
├── 感觉认知与协调/
└── 恢复与调节/
```

例如“单车踩踏”的主分类是 `体能与移动`，同时可以带有 `基础有氧`、`恢复能力`、`持续高强度`、`低冲击`等标签。

每个动作文件建议包含：

1. 动作名称与别名；
2. 动作目的和适用场景；
3. 动作描述与基本执行流程；
4. 所需器械、空间和安全准备；
5. 主要能力模块；
6. 支撑能力与可能限制；
7. 结构与动态力线观察；
8. 活动度、稳定性和组织耐受要求；
9. 力量、体能、速度或弹性要求；
10. 感觉输入与认知要求；
11. 训练变量：重量、强度、次数、时间、距离、速度、密度和休息；
12. 技术重点与质量标准；
13. 常见代偿与停止条件；
14. 退阶、进阶与跨模块组合；
15. 评估指标和真实任务迁移；
16. 已被哪些训练计划使用。

## 统一分析角度

动作分析至少回答：

- **目标角度**：为什么使用这个动作？
- **任务角度**：身体需要完成什么结果？
- **结构与力线角度**：足部、关节、骨盆、胸廓和脊柱如何承重、传力和调整？
- **能力模块角度**：主要能力、支撑能力和可能限制是什么？
- **训练条件角度**：负荷、动态、感觉、认知、环境和疲劳如何改变刺激？
- **执行角度**：哪些细节必须满足，哪些只是表现优化？
- **进阶角度**：怎样从可进入发展到可控制、可承载、可表现和可适应？
- **反馈角度**：如何判断动作质量、外部输出、认知表现、恢复和迁移？

## 动作文件命名

建议使用清晰的中文动作名，例如：

```text
高脚杯深蹲.md
行李箱走.md
低台阶上台阶.md
```

不要在动作库中把“深蹲 4×8”作为一个动作文件；组数、次数、重量和休息属于训练计划中的剂量，应在计划文件中引用动作库动作。

## 与训练计划的关系

- 动作库回答：这个动作是什么，如何分析和使用？
- 训练计划回答：本周哪一天为什么使用它，使用什么剂量和条件？
- 训练任务库回答：多个动作如何组成跨模块任务？

动作文件应保持相对稳定；计划文件记录具体个体、阶段和当天的训练处方。
