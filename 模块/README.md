# 模块文档说明

本目录用于保存“人类训练体系”各个能力模块的详细分析。

## 使用原则

- `总纲.md` 是整个体系的总设计方法论，不是本目录下某个模块的附属说明。
- 模块是分析身体的视角，不代表必须把训练拆成彼此独立的训练日。
- 每个模块都应说明它与其他模块的关系，以及如何通过动作任务、负荷、动态、感觉、认知和环境条件进行整合训练。
- 模块文档不能只列动作，还应分析目标、适应机制、训练条件、执行细节、评估指标、进阶和迁移。

## 模块文档建议结构

每个模块建议回答：

1. 这个模块在整体体系中解决什么问题？
2. 它包含哪些子能力？
3. 它与力线恢复、力量、体能、感觉—认知和其他模块如何相互作用？
4. 可以通过哪些身体任务和训练条件训练？
5. 如何从恢复阶段进阶到运动员式表现阶段？
6. 如何设置强度、负荷、速度、时间、密度和复杂度？
7. 如何评估改善，并判断是否迁移到真实运动？
8. 什么情况需要退阶、停止或寻求专业评估？

## 当前模块目录

- `体能/`：恢复能力、基础有氧、持续高强度、最大摄氧、重复冲刺、疲劳下动作能力；
- `力线恢复/`：下肢承重链、上肢—肩带—胸廓传力链、脊柱—胸廓—骨盆系统；
- `力量/`：最大力量、相对力量、力量耐力、单侧力量、等长、离心和快速发力；
- `活动度与关节控制/`：主动活动度、负重活动度、末端控制和关节协同；
- `速度爆发与弹性/`：加速、爆发、伸缩循环、弹性回弹和功率；
- `敏捷变向与反应/`：制动、变向、随机刺激、反应和决策；
- `神经肌肉协调与运动学习/`：本体感觉、视觉—动作协调、节奏、时机和动作学习；
- `组织耐受与冲击适应/`：肌肉、肌腱、韧带、骨骼、关节、落地、碰撞和渐进暴露；
- `训练任务库/`：将多个模块整合到具体身体任务中的任务卡和动作设计。
