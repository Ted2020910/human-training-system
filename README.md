# 人类训练认知

一个面向人类综合身体能力训练认知与体系设计的项目。

## 项目目标

本项目尝试构建一套接近运动员综合身体能力的人类训练体系。它不局限于健美式肌肉训练，而是从身体恢复、动作控制、力量、体能、速度、活动度、敏捷、反应、神经—肌肉协调、组织耐受和复杂环境适应等多个视角，建立可分析、可设计、可评估、可持续迭代的方法论。

## 核心思想

- 模块是分析身体的视角，不是彼此隔离的训练隔间；
- 动作任务是能力整合的载体；
- 训练计划不只是动作清单，还包括目标、能力、任务、动作组织、负荷、动态、感觉、认知、执行约束和反馈调整；
- 先恢复有效的力传递和身体控制，再逐步发展高水平综合表现；
- 训练既要发展身体输出，也要发展感觉输入、信息处理、决策和疲劳下的动作质量。

本项目用于训练体系研究与设计，不替代医疗诊断、康复评估或专业教练现场指导。对于持续疼痛、麻木、明显无力、近期外伤、关节卡锁或异常心肺症状，应先进行专业评估。
